3) Build a simple TCO model (first‑year and 3‑year) for Starter/Growth/Enterprise tiers
Create a small spreadsheet with these inputs per tier (in SAR):

Inputs (per terminal)

Hardware cost (one-time)

License: perpetual OR SaaS (monthly × 12)

Implementation/training (one-time)

Support/AMC (annual)

Connectivity (SIM/fixed line, if bundled)

Add‑ons (loyalty, advanced analytics, delivery integrations)

Expected annual price increase % (for renewals)

Formulas

Year‑1 cost = Hardware + License(12 months) + Implementation + Support + Connectivity + Add‑ons

Year‑2 cost = License(12 months × (1 + increase%)) + Support × (1 + increase%) + Connectivity + Add‑ons

Year‑3 cost = same logic as Year‑2

3‑year TCO = Year‑1 + Year‑2 + Year‑3

Cost per terminal per month = 3‑year TCO ÷ 36

Target price bands (use as sanity checks)

Starter: ~SAR 125–250/month equivalent (SoftPOS or basic terminal + core POS + ZATCA).

Growth: hardware ~USD 800–1,500 (~SAR 3,000–5,600) + SaaS or bundled rental.

Enterprise: hardware + advanced software ~USD 3,000–8,000 (~SAR 11,250–30,000) per station with volume discounts.
